Pi Remote web access

This page is served by the Pi Remote app on your phone, over TLS, to another computer on the same Wi-Fi network.

This is the walking skeleton: the page, the certificate and the on-demand server are in place. Prompts, streamed answers and audio arrive in a later stage, so there is nothing to do here yet.

When the browser warns about the self-signed certificate, compare the fingerprint it shows against the one in the app's Settings, then continue.
